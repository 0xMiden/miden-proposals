# Miden wallet connector

Authors: Miden team (devs@miden.team)  
Created: 04-03-2025
Status: Open
Deadline: 06-03-2025

## Abstract

> Short explanation of the proposal

Implement a wallet connector enabling EVM compatible wallets (e.g., Metamask, Coinbase wallet, Rabby, Phantom, and others) to interact with the Miden blockchain. Allowing users to manage assets and interact with smart contracts without having to change their preffered wallet interface.

## Motivation

> Why is this proposal needed?

The blockchain ecosystem now comprises millions of users already comfortable with EVM-compatible wallets. For Miden to achieve widespread adoption, it must meet users where they are rather than requiring them to adopt entirely new tooling. Enabling integration with existing popular wallets will:

1. Significantly lower the barrier to entry for new Miden users
2. Accelerate ecosystem growth by leveraging established wallet user bases
3. Enhance user experience by allowing seamless interaction with Miden through familiar interfaces

## Scope

> Boundaries and limitations of the work to be proposed

The proposal should cover to the minimum the following sections:

- Wallet connector implementation
- API reference (Miden -> EVM; EVM -> Miden)
- Documentation
- Examples
- Testing
- Security

## Requirements

The user should be able to:
- Create a Miden account using an EVM compatible wallet
- Interact with the Miden blockchain using an EVM compatible wallet
- Send funds to an existing Miden wallet
- Receive funds from an existing Miden wallet
- Deploy a Miden smart contract
- Interact with a Miden smart contract

The user should not have to:
- Install a proprietary Miden wallet
- Install a third party extension / software (e.g., Metamask snap)
